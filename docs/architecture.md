# نظرة عامة معمارية

- **الخلفية**: FastAPI + SQLModel مع SQLite افتراضياً. يتم توفير واجهات REST شاملة، ونظام إشعارات مبني على APScheduler، ودعم JWT مع تشفير بيانات حساسة باستخدام Fernet.
- **الواجهة**: React (Vite) مع تصميم RTL افتراضي، دعم PWA والعمل دون اتصال، وجداول TanStack Table، ورسوم Recharts.
- **المزامنة دون اتصال**: يتم استخدام Workbox لخدمة الملفات المحفوظة مسبقاً وصفوف Background Sync لأي عمليات POST/PUT/DELETE.
- **التنبيهات**: قنوات التلغرام والبريد الإلكتروني قابلة للتهيئة من خلال إعدادات التطبيق.
